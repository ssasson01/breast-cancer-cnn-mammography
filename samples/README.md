# Sample images

These 10 mammograms (5 benign, 5 malignant) are from the CBIS-DDSM dataset (mass subset, test split):

Lee, R. S., Gimenez, F., Hoogi, A., Miyake, K. K., Gorovoy, M., & Rubin, D. L. (2017).
A curated mammography data set for use in computer-aided detection and diagnosis research.
*Scientific Data*, 4, 170177. https://doi.org/10.1038/sdata.2017.177

Obtained via Kaggle: https://www.kaggle.com/datasets/awsaf49/cbis-ddsm-breast-cancer-image-dataset
